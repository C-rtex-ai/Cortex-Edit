# Cortex-Edit

Editor de vídeo para desktop, parte do ecossistema Cortex (Electron, Windows x64).

## Instalação

Baixe `Cortex-Edit.Setup.0.1.0.exe` na página de [Releases](https://github.com/C-rtex-ai/Cortex-Edit/releases/tag/Installers) e execute.

O instalador não é assinado digitalmente, então o Windows pode mostrar um aviso do SmartScreen.

## Código-fonte

O código-fonte não é publicado neste repositório.
